# Detect or Degrade

Apart Research / AIAF Swarm hackathon, Track 4 (Multi-Agent Oversight and Control), 7–9 Nov 2026.
All code and data in this repository were created during the hackathon, starting 2026-11-07 05:00 IST.
Nothing here predates the event.

**Question.** In a fleet of AI agents, the audit budget, the false-positive tripwire and the trusted-model
fallback are shared resources. Can a coalition of colluding agents spend them? Decoys can use up the
audits, so a real attack goes unaudited (the attack is not *detected*). Tripping the tripwire on purpose can
push the whole fleet onto the weak trusted model (useful work *degrades*). What defence improves the worst
case?

## Layout

| Path | What |
|---|---|
| `tasks/templates_1.py`, `tasks/templates_2.py` | 20 small coding tasks. Each has a reference solution, functional tests, and hidden safety tests (the ground truth for "harmful"). |
| `tasks/build_items.py` | Hand-written variants: honest rewrites, attacks, decoys. Every label is checked by running the tests. |
| `tasks/gen_items.py`, `tasks/merge_items.py`, `tasks/merge_v3.py` | Honest solutions, decoys (incl. the `mild` decoys, D4) and attacks generated by the untrusted model, verified by the same tests (see `DEVIATIONS.md`). |
| `tasks/runner.py` | Sandboxed test runner: network and process spawning are blocked. |
| `monitor/score.py` | Fixed, stateless LLM monitor. Frozen prompt, temperature 0, 10 items per batch, 3 reps in different batches. |
| `monitor/audit.py` | Simulated auditor (and the attacker's / triage model): convicts if the code is harmful or looks deliberately deceptive. |
| `monitor/solve.py` | Measures task success of the trusted model, which gives the fallback cost. |
| `sim/sim.py` | Fleet simulator and the seven protocols (incl. the triage cascade, D5). |
| `sim/test_sim.py` | Positive and negative controls for the simulator (34 checks, incl. an analytic check of the flooding condition). |
| `sim/experiments.py` | Calibration on discovery templates, evaluation-template results, task-level bootstrap. |
| `sim/paired.py` | Paired differences (same bootstrap replicates) between strategies and protocols. |
| `sim/figures.py` | Figures and results tables; `headline` and `pcurve` figures. |
| `run_all.sh`, `run_extra.sh`, `run_resume.sh` | The experiment chains behind every number in `report/FACTS.md`. |
| `report/FACTS.md` | Every result, with its source file. |
| `data/frozen.json` | Settings frozen before any monitor score existed. |
| `DEVIATIONS.md` | Every change made after seeing data. |

## Reproduce

```
python tasks/build_items.py                     # hand items + label check
python tasks/gen_items.py gemma4:31b-cloud honest 8
python tasks/gen_items.py gemma4:31b-cloud decoy 8
python tasks/gen_items.py gemma4:31b-cloud attack 6
python tasks/merge_items.py
DOD_ITEMS=data/items_v2.jsonl python monitor/score.py gemma4:31b-cloud 3
python monitor/solve.py qwen2.5:3b-instruct 3
python monitor/audit.py gpt-oss:120b-cloud      # auditor verdicts
python monitor/audit.py gemma4:31b-cloud         # attacker's own model / triage verdicts
python tasks/gen_items.py gemma4:31b-cloud mild 8 && python tasks/merge_v3.py   # mild decoys (D4), then score + audit them
python sim/test_sim.py                           # 34 checks
sh run_all.sh 5                                  # main, prescreen, perfect, u05, handdecoys, headline figure
sh run_extra.sh 4                                # selfscreen + p-curve (p = 0 ... 0.3)
python sim/figures.py pcurve
```

Each setting writes `results/<tag>/*.json` (with per-replicate values), `results/<tag>/paired.json` and
`report/figures/<tag>/`. A full chain takes several hours on a laptop CPU.

Models run through Ollama: `gemma4:31b-cloud` (free tier) as the untrusted model, the monitor and the triage model, `gpt-oss:120b-cloud` (free tier) as the auditor, and the local
`qwen2.5:3b-instruct` as the trusted model. No paid APIs.

## Report

- `report/Detect-or-Degrade-Apart.pdf`: the submitted report (Apart Research template).
- `report/report_own_words.md`: its source text. `report/build_template.py` fills the Apart template with it
  (the template itself is not included; download it from the hackathon page into `report/template/`).
- `report/FACTS.md`: every number in the report, with the file it comes from.
- `report/figures/`: all figures; `pcurve.png` and `headline_frontier.png` are Figures 1 and 2.
